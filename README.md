# MDViewer

**macOS 上的 Markdown 阅读与编辑，本该如此。**

MDViewer 是一款纯原生 macOS Markdown 阅读器与编辑器，用 SwiftUI + AppKit 构建，无 Electron，无 Web 套壳。它只做一件事：让你在 Mac 上写 Markdown、读 Markdown，体验像系统自带一样顺滑。编辑器与预览之间的双向同步精确到标题级别，一套 JSON 配置文件掌控所有排版细节，保存即生效。

---

## 为什么选 MDViewer

**真正的原生体验** -- 不是浏览器套个壳。启动快、内存省，快捷键和窗口行为跟 macOS 原生应用一致。

**编辑和预览真正同步** -- 在编辑区点击任意位置，预览区精确滚动到对应段落。反过来也行：点击预览区，编辑器跟着跳。定位以标题为锚点计算，代码块再长也不会让预览「飘」掉。

**一个 JSON 文件定义所有样式** -- 大多数 Markdown 编辑器的主题只能换个配色。MDViewer 的 `styles.json` 控制一切：编辑器字体、字号、行高、语法高亮色，以及预览区从 H1 到表格、代码块、引用的完整 CSS。保存文件的瞬间 app 热重载，所见即所得地调样式。

**中日文输入法零问题** -- 完整的 IME 支持，打中文、日文不会吞字、跳光标、断候选词。

## 视图模式

| 快捷键 | 模式 | 说明 |
|--------|------|------|
| ⌘1 | 编辑 | 纯编辑区，专注写作 |
| ⌘2 | 分栏 | 左侧编辑 + 右侧实时预览 |
| ⌘3 | 预览 | 全屏预览 + 左侧目录大纲（H1--H6，点击跳转） |

## 样式系统

三套内置样式，开箱即用：

| 样式 | 说明 |
|------|------|
| **GDS-Style**（默认） | 四色标题：H1 蓝 / H2 红 / H3 黄 / H4 绿，白色背景 |
| **Dark** | 深色背景，低对比度配色 |
| **Sepia** | 复古暖纸色调 |

想自定义？打开偏好设置（⌘,），点击「打开配置文件」，编辑 `styles.json`：

```
~/Library/Application Support/MDViewer/styles.json
```

每套样式分两部分：**编辑区**（字体、字号、行高、各元素高亮色）和**显示区**（覆盖所有 Markdown 元素的完整 CSS）。保存即重载，无需重启。配置文件损坏时自动恢复内置默认值。

## 编辑器

- Markdown 语法高亮：标题、粗体、斜体、行内代码、链接、删除线、引用块、代码块（颜色由当前样式定义）
- 行号显示
- ⌘F 查找与替换（系统原生 Find Bar）
- 代码块语法高亮（highlight.js，内置 Swift 支持）
- 图片自适应宽度

## 文件与窗口

- **⌘O** 打开文件 / **⌘N** 新建窗口 / **⌘⇧O** 打开文件夹侧栏（递归显示所有 `.md` 文件）
- Finder 双击、拖拽到窗口均可打开
- 最近文件列表（File > 打开最近文件，最多 10 条）
- 文件在外部被修改后自动刷新（FSEvents 监听）
- 每个文件独立窗口，状态完全隔离；空白窗口智能复用
- 工具栏显示未保存状态提示

## 保存与导出

| 快捷键 | 功能 |
|--------|------|
| ⌘S | 保存（新文件触发另存为） |
| ⌘⇧S | 另存为 |
| ⌘E | 导出 PDF |
| ⌘⇧E | 导出独立 HTML（CSS 内联，单文件可分享） |

## 缩放

⌘= / ⌘- / ⌘0（或工具栏按钮），范围 50%--300%。编辑区字号与预览区缩放保持同步，新窗口继承上次的缩放比例。

## 帮助

⌘? 打开内置使用指南。

## 构建要求

- macOS 14.0+
- Xcode 15+

## 构建方式

```bash
git clone https://github.com/dennylee2026/MDViewer.git
cd MDViewer
open MDViewer.xcodeproj
```

在 Xcode 中选择目标设备为 **My Mac**，按 **⌘R** 构建并运行。
