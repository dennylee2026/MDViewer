## 功能特性

### 文件管理
- **⌘O** 打开文件选择器，自动定位到上次所在目录
- **⌘N** 新建空白窗口
- **⌘⇧O** 打开文件夹，在左侧侧栏展示所有 `.md` / `.markdown` 文件（支持子目录递归）
- 支持从 Finder 双击打开、拖拽到窗口打开
- **File > 打开最近文件** 快速访问最近 10 条记录
- 文件变更后自动刷新（FSEvents 监听）

### 视图模式
| 快捷键 | 模式 | 说明 |
|--------|------|------|
| ⌘1 | 编辑 | 纯编辑区，无侧栏 |
| ⌘2 | 分栏 | 左侧编辑 + 右侧实时预览 |
| ⌘3 | 预览 | 纯预览 + 左侧目录大纲 |

### 编辑器
- Markdown 语法高亮：标题（Google 四色）、粗体、斜体、行内代码、链接、删除线、引用块、代码块
- 行号显示
- **⌘F** 查找 / 替换（内建 Find Bar）
- 中文 / 日文输入法（IME）全兼容
- 可选字体：SF Pro（默认）/ Menlo（等宽）/ Palatino（衬线），在偏好设置中配置

### 分栏同步
- 在编辑区点击光标，预览区自动滚动到对应位置
- 以最近标题为锚点计算定位，代码块不会导致高度偏移
- 目标元素在预览区保持与光标在编辑区相同的垂直比例

### 预览渲染
- 标题 Google 品牌四色：H1 蓝 / H2 红 / H3 黄 / H4 绿
- 代码块语法高亮（highlight.js，内置 Swift 支持）
- 图片自适应宽度
- 跟随系统明暗模式自动切换

### 主题
在 **⌘,** 偏好设置中选择预览主题：
- 跟随系统（默认）
- 始终明亮
- 始终暗色
- 复古纸张（Sepia）

### 目录大纲
- 预览模式（⌘3）左侧自动生成目录，支持 H1–H6 层级缩进
- 点击标题平滑滚动到对应位置

### 缩放
- **⌘=** / **⌘-** / **⌘0**（或工具栏按钮），范围 50%–300%
- 编辑区字号与预览区页面缩放同步
- 新窗口自动继承上次使用的缩放比例

### 保存与导出
| 快捷键 | 功能 |
|--------|------|
| ⌘S | 保存；新文件触发「另存为」对话框 |
| ⌘⇧S | 另存为 |
| ⌘E | 导出为 PDF（基于当前渲染） |
| ⌘⇧E | 导出为 HTML（内联主题 CSS，生成独立文件） |

### 多窗口
- 每个文件在独立窗口中打开，状态完全隔离
- 若当前窗口为空白未编辑，打开文件时直接复用，避免产生多余空窗口
- 工具栏显示橙色「Unsaved」提示未保存内容；保存后出现「Saved ✓」短暂提示

### 帮助
- **⌘?** 打开内置使用指南

## 构建要求

- macOS 14.0+
- Xcode 15+

## 构建方式

```bash
git clone https://github.com/dennylee2026/MDViewer.git
cd MDViewer
open MDViewer.xcodeproj
```

在 Xcode 中选择目标设备为 **My Mac**，按 **⌘R** 构建并运行。
