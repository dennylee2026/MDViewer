# MDViewer

**你的 Mac 值得一款真正的 Markdown 编辑器。**

大多数 Markdown 工具要么是塞进浏览器壳的网页应用，要么就笨得像在用记事本。MDViewer 不同——它用 SwiftUI + AppKit 从零原生构建，启动如闪，内存占用极低，窗口行为和键盘快捷键跟系统原生应用别无二致。写 Markdown，不该是一件将就的事。

---

## 为什么是 MDViewer

**原生，而不是包了层皮** — 没有 Electron，没有 Web 套壳，没有 Chromium 进程在后台偷吃内存。MDViewer 直接跑在 AppKit 上，启动时间以毫秒计，关掉窗口就真的关掉了。

**编辑与预览，丝滑联动** — 在编辑区任意位置点击，预览区精确跳到对应段落；在预览区点击，编辑器同步定位。定位逻辑以标题为锚点，代码块再长也不会让预览「飞」掉。写长文档时，这一点能救命。

**样式由你掌控，改了马上看到** — 其他编辑器换主题最多换个配色。MDViewer 的 `styles.json` 控制一切：编辑器字体、字号、行高、语法高亮色，以及预览区从 H1 到表格、代码块、引用块的完整 CSS。保存文件，app 热重载，所见即所得地调到满意为止。

**中日文输入法，零问题** — 打中文、日文不吞字，不跳光标，候选词不会被打断。这本该是基本功，但做到的编辑器少之又少。

**导出灵活，桌面移动全覆盖** — 一键导出桌面 PDF、移动端 PDF（390pt 宽，专为手机阅读优化）、移动端 PNG 截图、独立 HTML，或者一次「全部导出」全拿到。

## 视图模式

| 快捷键 | 模式 | 说明 |
|--------|------|------|
| ⌘1 | 编辑 | 纯编辑区，专注写作，不分心 |
| ⌘2 | 分栏 | 左侧编辑 + 右侧实时预览，一边写一边看 |
| ⌘3 | 预览 | 全屏预览 + 左侧目录大纲（H1–H6，点击跳转） |

## 样式系统

三套内置样式，开箱即用：

| 样式 | 说明 |
|------|------|
| **GDS-Style**（默认） | 四色标题：H1 蓝 / H2 红 / H3 黄 / H4 绿，白色背景，信息层级一目了然 |
| **Dark** | 深色背景，低对比度配色，长时间写作不伤眼 |
| **Sepia** | 复古暖纸色调，读长文的最佳氛围 |

想自定义？打开偏好设置（⌘,），点击「打开配置文件」，编辑 `styles.json`：

```
~/Library/Application Support/MDViewer/styles.json
```

每套样式分两部分：**编辑区**（字体、字号、行高、各元素高亮色）和**显示区**（覆盖所有 Markdown 元素的完整 CSS）。保存即重载，无需重启。配置文件损坏时自动恢复内置默认值。

## 编辑器

- Markdown 语法高亮：标题、粗体、斜体、行内代码、链接、删除线、引用块、代码块（颜色由当前样式定义）
- 行号显示
- ⌘F 查找与替换（系统原生 Find Bar）
- 代码块语法高亮（highlight.js，内置 Swift 支持）
- 图片自适应宽度

## 文件与窗口

- **⌘O** 打开文件 / **⌘N** 新建窗口 / **⌘⇧O** 打开文件夹侧栏（递归显示所有 `.md` 文件）
- Finder 双击、拖拽到窗口均可打开
- 最近文件列表（File > 打开最近文件，最多 10 条）
- 文件在外部被修改后自动刷新（FSEvents 监听）
- 每个文件独立窗口，状态完全隔离；空白窗口智能复用
- 工具栏显示未保存状态提示

## 保存与导出

| 快捷键 | 功能 |
|--------|------|
| ⌘S | 保存（新文件触发另存为） |
| ⌘⇧S | 另存为 |
| ⌘E | 导出桌面 PDF |
| ⌘⇧E | 导出独立 HTML（CSS 内联，单文件可分享） |
| — | 导出移动端 PDF（390pt 宽，手机阅读专用） |
| — | 导出移动端 PNG（高清截图，社交分享友好） |
| — | 全部导出（桌面 PDF + 移动 PDF + 移动 PNG 一次搞定） |

## 缩放

⌘= / ⌘- / ⌘0（或工具栏按钮），范围 50%–300%。编辑区字号与预览区缩放保持同步，新窗口继承上次的缩放比例。

## 构建要求

- macOS 14.0+
- Xcode 15+

## 构建方式

```bash
git clone https://github.com/dennylee2026/MDViewer.git
cd MDViewer
open MDViewer.xcodeproj
```

在 Xcode 中选择目标设备为 **My Mac**，按 **⌘R** 构建并运行。

## 开发

日常开发在 `dev` 分支进行，功能稳定后合并到 `main`。变更记录见 [CHANGELOG.md](CHANGELOG.md)。
