# MDViewer Roadmap

## 核心功能（按优先级）

1. ✅ 打开并渲染单个 `.md` 文件，排版美观可读（2026-04-09）
2. ✅ 支持从 Finder 双击打开、拖拽打开（2026-04-09）
3. ✅ 内置至少两套阅读主题（明亮 / 暗色），跟随系统外观切换（2026-04-09）
4. ✅ 文件变更时自动刷新（监听文件系统变化）（2026-04-09）
5. ✅ 目录大纲侧栏（基于标题层级生成）（2026-04-09）

---

## 编辑器功能

### A · 核心编辑器
- [ ] 新建 `EditorView.swift`：`NSTextView` 包装，等宽字体，软换行，双向绑定 `markdownContent`，每次按键实时触发预览更新

### B · 视图模式
- [ ] `AppState` 加 `viewMode` 枚举：`.split` / `.viewer` / `.editor`
- [ ] 工具栏加三模式切换按钮（⌘1 编辑 / ⌘2 分栏 / ⌘3 预览）
- [ ] `ContentView` 布局：根据 `viewMode` 切换 HSplitView / 纯编辑器 / 纯预览

### C · 启动行为
- [ ] 直接启动 app（无文件）→ 分栏模式，左侧空白编辑器，右侧空白预览
- [ ] 通过 Finder / 拖拽 / ⌘O 打开 `.md` 文件 → 预览模式（Viewer only）

### D · 侧栏规则
- [ ] `.editor` 模式：隐藏大纲侧栏
- [ ] `.split` 模式：隐藏大纲侧栏
- [ ] `.viewer` 模式：显示大纲侧栏（现有行为）

### E · 文件操作
- [ ] ⌘N 新建空白缓冲区，切换到分栏模式
- [ ] ⌘S 保存；新文件弹「存为」面板
- [ ] ⌘⇧S 另存为
- [ ] `AppState` 加 `isDirty`，标题栏文件名后显示 `•` 表示未保存
- [ ] 打开新文件前有未保存内容时弹确认对话框

### F · 页面缩放
- [ ] 工具栏加缩放控件（`-` / 当前比例 / `+`，默认 100%）
- [ ] 快捷键 ⌘= 放大 / ⌘- 缩小 / ⌘0 重置
- [ ] 通过 `WKWebView.pageZoom` 实现，不改 CSS

### G · 后续增强
- [x] 编辑器内 Markdown 语法高亮（2026-04-09）
- [x] 编辑器行号显示（2026-04-09）
- [x] 编辑器与预览区滚动位置同步（2026-04-09）
- [x] ⌘F 查找替换（2026-04-09）
